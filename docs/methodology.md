# Methodology

## Research Design

This project uses quantitative analysis of country-level data to examine patterns in the Gender Development Index between 1990 and 2021.

## Unit of Analysis

The primary unit of analysis is the country.

## Research Questions

The analysis examines:

1. Cross-country variation in GDI.
2. Differences in GDI across human development groups.
3. Geographic differences in GDI.
4. The association between GDI and HDI rank.
5. Changes in GDI over time.

## Analytical Methods

The analysis includes:

- Data quality assessment
- Missing-data assessment
- Descriptive statistics
- Exploratory data visualization
- Difference-in-means testing
- Correlation analysis
- Linear regression
- Longitudinal comparison

## Missing Data

Missing observations were assessed before conducting statistical analysis.

Earlier years contain more missing GDI observations than later years, meaning that the number of countries contributing to annual estimates varies over time.

## Statistical Interpretation

Results are interpreted as descriptive patterns and statistical associations.

The observational nature of the data means that the analysis does not establish causal relationships.

## Limitations

The analysis is limited by:

- Missing observations
- Country-level aggregation
- A relatively small number of explanatory variables
- Potential differences in country coverage across years
- The observational nature of the dataset
